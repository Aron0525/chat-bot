# chat-bot

<div align="center">

**挂在聊天软件旁边的 AI 副驾：读当前对话，判断对方想要什么，给出可一键填入的回复。**

Android 11+ · 仅 arm64-v8a · 不自动发送

## 它是什么

一个 Android 无障碍悬浮助手。你在 QQ、X（推特）、飞书、WhatsApp 里聊天时，它读取屏幕上**正在显示**的对话，调你自己配置的模型接口做判断和起草，把候选回复填进输入框。

**发送键永远由你手动点。** 程序不碰发送、不碰转账红包。

## 核心功能

### 1. 判断 + 起草回复

先用判断模型（Jev / TypeSafe 兼容接口）回答 7 个问题——对方真实意图、危险等级、该不该现在回、最合适什么动作——再据此起草候选回复，最后排一次序。不是"让模型随便编一句"，是先想清楚再写。

### 2. 两种填入方式（设置里切换）

| | 点选候选 | 一键直填（仅推特） |
|---|---|---|
| 界面 | 聊天界面上方的分析卡片 | 可拖动的小绿球 |
| 动作 | 卡片列 3 条，点「填入」 | 点一下：分析 + 直接填第 1 条 |
| 不满意 | 点「换一组」重新生成 | 再点：换第 2 条 → 第 3 条 → 回到第 1 条 |
| 范围 | 所有已适配 App | 只有推特 |

### 3. 推特按内容写评论

推特上不再只是"顺着聊"，而是读帖子正文 + 已有回复 + 作者，按评论助手的方式出候选。每条评论都做两件事：**对内容有具体回应 + 表达自己的观点**。

四种风格可选（设置 → 分析 → 回复风格）：混合（三条角度不同）/ 温和友好 / 有观点 / 幽默玩梗。评论语言跟随原帖。

### 4. 在线更新

设置 → 关于与隐私 →「检查更新」，查 GitHub Releases，下载完交给系统安装器。启动时静默检查（最多 6 小时一次），发现新版本只在首页多一行提示。

### 5. 知识库与会话白名单

本地知识库 + 联系人档案，分析时自动带上命中的笔记和这个人的历史，回复不会跟你的设定打架。白名单可以限定只在某些会话里生效。

## 平台支持

| App | 状态 | 采集方式 | 备注 |
|---|---|---|---|
| QQ Android | ✅ 全链路 | 无障碍读节点 | 9.3.50 实测 |
| X / Twitter | ✅ 全链路 | 解析 Compose 节点 content-desc | 私信页 + 帖子页 |
| 飞书 / Lark | ✅ OCR 兜底 | 读气泡矩形 + ML Kit 离线 OCR | 正文自绘，不在无障碍树里 |

| 其它 App | ✅ 手动 | 悬浮窗菜单「截屏识别一次」 | 不自动分段，全部当作对方所说 |

> **使用风险**：在第三方 App 里使用本工具，可能不符合该 App 的用户协议，账号有被限制的风险，请自行判断。

## 快速开始

**1. 装包**

```bash
adb install -r cn/apk/chat-bot-v1.11.apk
```

或直接下载：[chat-bot-v1.11.apk](apk/chat-bot-v1.11.apk)

> 换过签名，从更早的 debug 版升级需要先卸载旧版。

**2. 填密钥**

打开 App → 设置 →「接口」。最简单只填「判断接口」的 OpenRouter API Key，其余两栏留空会自动继承。想换回复模型就在「回复接口」选预设或自填地址。每张卡都有连通测试。

**3. 开权限**

按主页的清单逐项打开：无障碍权限、悬浮窗权限、自启动 + 省电无限制（小米 / HyperOS 必须，否则服务被冻结）。

**4. 用起来**

进聊天界面，对方发消息后自动分析出卡片；或在设置里切成「一键直填」，点推特旁边的小绿球。

## 发版

```bash
# 改 cn/app/build.gradle.kts 的 versionCode / versionName
# 打 tag 推送，CI 会自动构建签名包并发 Release
git tag v1.12
git push origin v1.12
```

CI 需要四个 Secrets：`ANDROID_KEYSTORE_BASE64`、`ANDROID_STORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`。tag 和 `versionName` 对不上会直接失败。

## 编译

```bash
cd cn
./gradlew assembleDebug
```

需要 JDK 17 + Android SDK 35。本机 E 盘有 aapt2 的坑，详见 [docs/BUILD-NOTES.md](docs/BUILD-NOTES.md)。

## 目录

```
cn/          国内版 Android 工程（主）
  app/src/main/java/com/jev/probe/
    capture/   无障碍采集（QQ / X / 飞书 / WhatsApp 适配器）
    jev/       模型客户端（判断、起草、评论提示词）
    overlay/   悬浮窗（分析卡片 + 一键直填球）
    update/    在线更新
    core/      数据模型与设置
global/      海外版工程
.github/     CI 流水线
```

## 隐私

- 聊天内容只发给你自己配置的模型接口，作者不运营中转服务器
- 密钥存在 App 私有空间
- 截图只在本机 OCR，不上传
- 第三方服务商如何处理收到的内容，以其隐私政策为准
